# At Home Cards

A planned collection of custom Lovelace cards for Home Assistant, based on the cards in the [standalone Home Assistant dashboard](https://github.com/SamerBerjawi/had-homeassistantdashboard).

## Project status

At Home Cards is in planning. The first installable release and Marketplace listing are pending.

## Planned scope

The goal is to bring the full dashboard card collection to Lovelace. This includes overview cards, room tiles, and individual entity cards, with examples spanning lighting, weather, energy, media, and cameras.

Each card will be addable individually in the Home Assistant dashboard editor. Where relevant, the editor will let users choose entities or areas, configure controls and display options, and resize the card using the Sections layout.

## Distribution

This repository is intended for releases of At Home Cards as a Home Assistant Marketplace dashboard plugin. The planned workflow keeps development in the linked dashboard repository and publishes versioned card releases here. Installation instructions will accompany the first release.
